# Screen TUI

GNU Screen 的 TUI 工具。

## 项目背景

在服务器使用 CodeX 之类的 AI 工具，为了防止 SSH 断开后任务终止，可以使用 Screen 执行。
为了简化 Screen 使用而创建的 TUI 工具。

## 核心功能

1. 创建新的 Screen Session
2. 查看已经存在的 Screen Session/
3. 连接已有的 Screen Session。
4. 对手机等小屏设备进行优化。
  1. 小屏和宽屏采用两套界面。
  2. 小屏时只显示少量必要信息（比如不帮助信息等）。
